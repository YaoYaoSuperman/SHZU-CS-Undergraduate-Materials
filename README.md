## 📝 简介

> **"知行合一，学以致用"**

本仓库用于系统地整理和归档大学本科期间（2021-2025）的课内学习资源，包括核心专业课、实践项目、人工智能课程以及毕业相关资料。所有资料均按照 **HUSTER-CS 规范** 进行组织，便于复习、总结和后续的职业发展。

---

## 🗂️ 目录结构

```
课内/
├── 📦 01-专业核心课/          # 核心专业课（计算机基础、编译原理、软件测试等）

├── 🤖 03-人工智能/            # AI 相关课程（数据挖掘、深度学习、网络编程）

```

## 📚 内容说明

### 📦 01-专业核心课
- **计算机基础**：算法与数据结构、操作系统原理等
- **编译原理**：词法分析、语法分析、代码生成
- **软件测试**：单元测试、集成测试、性能测试
- **单片机**：STM32 开发、嵌入式系统基础

### 🛠️ 02-实践与项目
- **嵌入式系统**：Linux 内核开发、设备驱动
- **数字图像处理**：图像算法、滤波器、边缘检测
- **数字逻辑**：Multisim 仿真、逻辑电路设计
- **工程实训**：全栈开发项目（Python/React）

### 🤖 03-人工智能
- **数据挖掘**：分类、聚类、关联规则
- **深度学习**：CNN、RNN、PyTorch、TensorFlow
- **网络编程**：Socket 编程、HTTP/HTTPS、TCP/IP

### 📚 04-公共课
- **形势与政策**：时政分析、理论联系实际
- **考研学习**：数学、英语、政治复习资料

### 🎓 05-毕业相关
- **毕业设计**：基于深度学习的图像识别系统
- **考研资料**：408、404、数一复习计划
- **毕业论文-14天挑战**：14天完成毕业论文的高效方法
