## 📝 简介

> **"知行合一，学以致用"**

本仓库用于系统地整理和归档大学本科期间（2021-2025）的课内学习资源，包括核心专业课、实践项目、公共课程以及毕业相关资料。所有资料均按照 **SHZUER-CS 规范** 进行组织，便于复习、总结和后续的职业发展。

## 📚 内容说明

### 📦 00-期末卷汇总-14套
- 各科期末/补考/期中试卷汇总（14套）
- 涵盖：计算方法、C语言、Python、人工智能、单片机、操作系统、数据库、概率论、编译原理、计算机组成原理、计算机网络等

### 📦 01-专业核心课
- **编程基础**：C语言、Python
- **核心理论**：数据结构、算法设计、操作系统、计算机组成原理、计算机网络
- **系统方向**：编译原理、软件工程、数据库、计算方法
- **安全方向**：网络安全
- **智能方向**：人工智能、数据挖掘
- **其他**：信息检索、单片机

### 🛠️ 02-实践与项目
- **嵌入式系统**：Linux 内核开发、设备驱动
- **工程实训**：图书销售权限系统
- **数字图像处理**：图像算法与实践
- **数字电路**：作业与实验

### 📚 03-公共课
- **政治**：形势与政策等思政课程
- **创新创业**：创新创业选修课
- **职业规划**
- **其他选修课**

### 🎓 04-毕业相关
- **开题**：选题与开题报告
- **中期答辩**：中期检查材料与请假表格
- **指导记录**
- **毕业论文**
